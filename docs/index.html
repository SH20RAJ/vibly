Installation

npm install vibly video.js
import videojs from 'video.js';
import 'video.js/dist/video-js.css';
import 'vibly/dist/vibly.css';
import Vibly from 'vibly';
<!-- Video.js CSS -->
<link href="https://unpkg.com/video.js/dist/video-js.min.css" rel="stylesheet">
<!-- Vibly CSS -->
<link href="https://unpkg.com/vibly/dist/vibly.css" rel="stylesheet">
<!-- Video.js & Vibly JS -->
<script src="https://unpkg.com/video.js/dist/video.min.js"></script>
<script src="https://unpkg.com/vibly/dist/vibly.min.js"></script>

Usage

<video id="my-player" class="video-js vibly-theme-default" controls>
  <source src="https://example.com/video.mp4" type="video/mp4">
  <track kind="captions" src="https://example.com/captions-en.vtt" srclang="en" label="English" default>
</video>

<script>
  const player = videojs('my-player');
  player.vibly({
    theme: 'default',
    fluid: true,
    aspectRatio: '16:9',
    playbackRates: [0.5, 1, 1.5, 2]
  });
</script>

Themes

Default Theme

A clean, modern theme with blue accents

player.vibly({
  theme: 'default'
});

City Theme

An urban theme with orange accents and square corners

player.vibly({
  theme: 'city'
});

Forest Theme

A nature-inspired theme with green accents and rounded corners

player.vibly({
  theme: 'forest'
});

API Reference

Methods

Method Description
player.vibly(options) Initialize the Vibly plugin with options
player.vibly().setTheme(theme) Change the theme of the player
player.vibly().getOptions() Get the current options
player.vibly().updateOptions(options) Update options at runtime

Options

Option Type Default Description
theme String 'default' The theme to use. Available themes: 'default', 'city', 'forest'
fluid Boolean true Whether to use fluid (responsive) mode
aspectRatio String '16:9' The aspect ratio to use in fluid mode
playbackRates Array [0.5, 1, 1.5, 2] The playback rates to show in the menu
hls Object { enabled: true, overrideNative: true, config: {} } HLS streaming options
dash Object { enabled: true, overrideNative: true, config: {} } DASH streaming options

Events

Event Description
vibly.ready Fired when the player is ready
vibly.themechange Fired when the theme is changed
vibly.play Fired when the player starts playing
vibly.pause Fired when the player is paused
vibly.ended Fired when the video ends
